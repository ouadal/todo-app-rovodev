# 🚀 Démarrage rapide - Options gratuites

## Option 1: Railway (Recommandée)
1. **Créez un compte** : https://railway.app (gratuit avec GitHub)
2. **Nouveau projet** → "Provision MySQL" 
3. **Copiez les infos** dans `.env.local`
4. **Lancez** : `npm run dev`

## Option 2: SQLite Local (Le plus simple)
Si vous voulez éviter les services externes, je peux configurer SQLite :
- ✅ Pas besoin de compte externe
- ✅ Base de données dans un fichier local
- ✅ Fonctionne instantanément

## Option 3: Aiven.io
- ✅ Complètement gratuit
- ✅ MySQL/PostgreSQL
- ✅ 1 mois sans limite
